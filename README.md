# TokTickIT

TokTickIT is an IT service desk application developed for CPE 334 Introduction to Software Engineering in the Age of AI Agents.

## Lab 1 Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Bootstrap

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL
- Prisma

### Testing
- Vitest
- Supertest

## Prerequisites

Before running the project, make sure the following are installed:

- Node.js
- npm
- PostgreSQL
